# GE AMIZADE - Website Institucional

Este repositório contém o código-fonte do website do **Grupo Escoteiro Amizade 66SP**, desenvolvido com tecnologias modernas de front-end focadas em performance, SEO e animações fluidas.

## 🚀 Tecnologias Utilizadas

- **[Next.js 16](https://nextjs.org/)** - Framework React com App Router.
- **[React 19](https://react.dev/)** - Biblioteca para construção de interfaces.
- **[Tailwind CSS v4](https://tailwindcss.com/)** - Estilização utilitária de alta performance.
- **[Lucide React](https://lucide.dev/)** - Biblioteca de ícones leve e consistente.
- **TypeScript** - Tipagem estática para maior segurança no código.

## 📋 Pré-requisitos

Certifique-se de ter o **Node.js** instalado (versão 20 ou superior recomendada).
